Ask Claude for a video.Get an MP4 back.

Make

Four ways to make a video.One renderer underneath.

Ask an agent, write JSON, design in HTML and Tailwind, or drop down to code. Every path ends in the same frame-exact MP4.

Agents write a few lines, not a codebase.

An agent describes the video as short JSON and Clipframe does the animation. Changes are small, checked edits, so a whole promo costs a few hundred tokens instead of thousands of lines of React.

  • A one-line menu of every block for the model
  • Atomic edit ops with undo-friendly results
  • Errors a model can fix: s3.props.title: required
ops.json · from your agent
// "Add a stats scene and make it orange"
[
  { "op": "add_scene", "scene": {
      "block": "stats-counter",
      "props": { "items": [{ "value": 128, "label": "Teams" }] } } },
  { "op": "set_theme", "patch": { "primary": "#F97316" } }
]

A video is a list of scenes.

Pick a block, set its props, choose a transition. Themes, music, voice-over and sound effects live in the same file. Generate it from your data and render thousands of variations.

  • 20 blocks: UI mockups, cursor clicks, pricing, stats, outros
  • 16:9, 9:16, 1:1, 4:5, 4:3 at 720p or 1080p, 30 or 60 fps
  • clipframe render project.json for an MP4
project.json
{
  "meta": { "format": "9:16", "fps": 30, "resolution": "1080p" },
  "scenes": [
    { "block": "title-reveal", "duration": 3,
      "props": { "title": "Meet TaskFlow" } },
    { "block": "ui-mockup", "duration": 4,
      "props": { "asset": "shot", "frame": "phone" },
      "transition": { "type": "slide", "duration": 0.5 } }
  ],
  "audio": { "music": "song", "duck": 0.3 }
}

Real HTML and CSS, on the video clock.

Flexbox, grid, gradients, blur, 3D transforms, web fonts and Tailwind v4, compiled in the browser. @keyframes play frame-exact, and var(--t) gives you the time.

  • Tailwind compiled with no build step
  • Any Google Font, project images with asset:ID
  • Frames wait for their fonts. No flashes, ever
an html scene
{ "block": "html", "duration": 4, "props": {
  "tailwind": true,
  "html": "<h1 class='rise text-[140px] font-bold'>
            Hello <span class='text-violet-400'>HTML</span>
          </h1>
          <div class='h-2 bg-white' style='width:calc(var(--p)*100%)'/>",
  "css": ".rise{animation:rise .8s both}
          @keyframes rise{from{opacity:0;translate:0 60px}}"
} }

Code when you need it. React too.

A block is one small file: a schema and a function that returns HTML (or draws on a canvas) for each frame. Use interpolate and spring, or render a React component to markup.

  • Plain JavaScript, TypeScript or React
  • Remotion-style interpolate, spring, easing
  • Same block in the player, the browser and the CLI
price.js
export default ({ z, defineHtmlBlock, interpolate }) =>
  defineHtmlBlock({
    id: "price", category: "data", defaultDuration: 3,
    schema: z.object({ price: z.number().default(29) }),
    tailwind: true,
    html: (p, f) => {
      const n = Math.round(p.price * interpolate(f.t, [0, 1.5], [0, 1]));
      return `<b class="text-[200px]">$${n}</b>`;
    },
  });

08

Questions

Short answers.Honest ones.

Can Claude make videos with Clipframe?

Yes. Add the MCP server (claude mcp add clipframe -- npx -y github:ferdousmikdad/clipframe mcp) or the Agent Skill, then ask for a video. Claude writes the project, renders frames to check them, and renders the MP4 on your computer. The same works in Claude Desktop, Cursor, Codex and other MCP apps.

Is it really free for my company?

Yes. Clipframe is MIT licensed: use it commercially at any company size, with no seats, no render fees and no sign-up. Fonts are SIL OFL and the icons are ISC, both free for commercial use.

Can I bring my Remotion project over?

Not unchanged. Clipframe is not a drop-in replacement: scenes are JSON blocks, HTML or small code blocks rather than React trees. The animation helpers (interpolate, spring, easing) work the same way, so porting a component is usually quick, and React components can be rendered to HTML per frame.

Which browsers can export?

Chrome and Edge, which have WebCodecs video encoding. Every modern browser can preview. The CLI uses headless Chrome, so server rendering works anywhere Chrome runs.

Can I render on a server?

Yes: clipframe render project.json runs headless Chrome and writes an MP4. Run it in CI, a container or a queue worker. There is no hosted serverless service yet.

What can't the HTML scenes do?

Scripts inside the HTML don't run (logic goes in a code block), and <video> or <iframe> can't be embedded inside HTML. Put a video scene underneath an HTML overlay instead.

Do I need to install anything to try it?

No. The playground and the video at the top of this page render and export entirely in your browser.
